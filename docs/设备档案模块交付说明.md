# 设备档案模块交付说明

低代码生成产物已按交付要求整理：命名体现"设备档案"业务含义、关键字段与状态枚举带中文注释、不含演示菜单。

## 一、后端（`backend/jeecg-module-system/jeecg-system-biz`）

包路径：`org.jeecg.modules.device`

| 文件 | 说明 |
| --- | --- |
| `entity/DeviceArchive.java` | 设备档案实体（表 `device_archive`），字段均带中文注释 |
| `enums/DeviceStatusEnum.java` | 设备状态枚举：1在用 / 2维修 / 3停用 / 4报废，与字典 `device_status` 一致 |
| `mapper/DeviceArchiveMapper.java` | 设备档案 Mapper |
| `mapper/xml/DeviceArchiveMapper.xml` | 按设备编号查询的 SQL |
| `service/IDeviceArchiveService.java` | 设备档案 Service 接口 |
| `service/impl/DeviceArchiveServiceImpl.java` | 设备档案 Service 实现 |
| `controller/DeviceArchiveController.java` | 设备档案控制器 |

### 接口路径（统一前缀 `/device/archive`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/device/archive/list` | 分页列表查询 |
| POST | `/device/archive/add` | 新增设备 |
| PUT/POST | `/device/archive/edit` | 编辑设备 |
| DELETE | `/device/archive/delete` | 删除设备 |
| DELETE | `/device/archive/deleteBatch` | 批量删除 |
| GET | `/device/archive/queryById` | 按 id 查询 |
| GET | `/device/archive/exportXls` | 导出 Excel |
| POST | `/device/archive/importExcel` | 导入 Excel |

## 二、前端（`frontend/src/views/device/archive/`）

| 文件 | 说明 |
| --- | --- |
| `DeviceArchiveList.vue` | 设备档案列表页（查询、新增、编辑、删除、导入导出） |
| `components/DeviceArchiveModal.vue` | 设备档案新增/编辑弹窗 |
| `deviceArchive.data.ts` | 列定义、查询表单、编辑表单（中文 label，状态字段注释取值含义） |
| `deviceArchive.api.ts` | 接口封装，路径与后端 `/device/archive/**` 对应 |

前端为动态路由，菜单组件路径 `device/archive/DeviceArchiveList` 即映射到列表页，无需手工注册路由。

## 三、数据库脚本（`db/`）

| 脚本 | 说明 |
| --- | --- |
| `device_archive.sql` | 设备档案增量脚本：`device_archive` 建表、`device_status` 字典、设备档案菜单及 admin 角色授权（仅本模块菜单，无示例菜单）。MySQL 语法，与主初始化脚本一样可由 db-init 转换执行 |
| `cleanup_demo_menus.sql` | 示例菜单清理脚本：删除官方种子数据中的"导航示例""组件示例"等 177 个演示菜单及其角色关联，避免无用示例菜单混入交付 |

### 使用方式

```bash
# 初始化完成后，在 SQL Server 中依次执行（或用转换器先行转换）：
# 1) 设备档案建表 + 字典 + 菜单 + admin 授权
db/device_archive.sql
# 2) 清理官方示例菜单（可选，建议交付环境执行）
db/cleanup_demo_menus.sql
```

执行后 admin 重新登录即可看到"设备管理 → 设备档案"菜单。

## 四、关键字段与状态枚举

- `device_code` 设备编号（唯一业务标识）
- `device_name` 设备名称；`device_model` 规格型号；`device_category` 设备类别
- `manufacturer` 生产厂商；`purchase_date` 购置日期；`install_location` 安装位置
- `device_status` 设备状态（字典 `device_status`）：**1 在用 / 2 维修 / 3 停用 / 4 报废**
- `responsible_person` 负责人；`remark` 备注
